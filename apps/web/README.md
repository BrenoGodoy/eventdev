# EventDev Web

Interface Next.js construída com App Router, TypeScript e CSS Modules. A
documentação completa está no [README principal](../../README.md).

```bash
npm run dev --workspace=web
npm run build --workspace=web
npm run start --workspace=web
npm run lint --workspace=web
```

Use `NEXT_PUBLIC_API_URL` para apontar a aplicação para a API NestJS.
